## 🎯 เป้าหมาย

ให้ระบบจัดการ MCP servers (stdio/SSE) + list/call tools — เพื่อให้ Console ใช้ MCP tools ตรงๆ (เป็น MCP host แบบ Jan)

## 📂 ไฟล์ที่สร้าง/แก้

| ไฟล์ | งาน |
|------|-----|
| `weight_stream/server/mcp_host.py` | **ใหม่** — MCPServerStore (JSON) + MCPHost (connect/list/call) |
| `weight_stream/server/schemas.py` | เพิ่ม `MCPServerCreate` (module-level) |
| `weight_stream/server/api_server.py` | เพิ่ม 5 routes `/v1/mcp/*` |
| `pyproject.toml` | เพิ่ม `mcp` extra (optional dependency) |

## 🔌 API

| Method | Path | ฟังก์ชัน |
|--------|------|---------|
| GET | `/v1/mcp/servers` | list configs |
| POST | `/v1/mcp/servers` | add/update (201) |
| DELETE | `/v1/mcp/servers/{id}` | delete (404 ถ้าไม่พบ) |
| GET | `/v1/mcp/tools` | list tools (connect servers) |
| POST | `/v1/mcp/tools/{server}/{tool}/call` | call tool |

## 📌 ข้อจำกัด (honest)

- **ต้อง `pip install mcp`** (extra) — store ทำงานได้เสมอ แต่ list_tools/call_tool ต้องมี mcp
- **MCP host ใช้สำหรับ Console โดยตรง** — สำหรับ IDE ต่อเข้า ใช้ P7.3 (tool-calling protocol) แทน
- **เชื่อมต่อจริง** (stdio server) ยังไม่ทดสอบ E2E — ต้องมี MCP server จริง (เช่น npx filesystem) — งาน QA ต่อ
