# 📋 P7.2 Brief — Assistant Management

> **Status:** ✅ เสร็จ (backend) · **Date:** 2026-08-04

## 🎯 เป้าหมาย

ให้ผู้ใช้สร้าง/แก้ไข/ลบ/เลือก **assistant** (persona) — ชุด system prompt + model + params ที่บันทึกไว้ เพื่อสลับโหมดแชทได้เร็ว (เหมือน Jan)

## 📂 ไฟล์ที่สร้าง/แก้

| ไฟล์ | งาน |
|------|-----|
| `weight_stream/server/assistants.py` | **ใหม่** — AssistantStore (JSON-file CRUD, thread-safe) |
| `weight_stream/server/schemas.py` | เพิ่ม `AssistantCreate` / `AssistantUpdate` (module-level) |
| `weight_stream/server/api_server.py` | เพิ่ม 5 routes `/v1/assistants` (CRUD) |

## 🔌 API

| Method | Path | ฟังก์ชัน |
|--------|------|---------|
| GET | `/v1/assistants` | list |
| GET | `/v1/assistants/{id}` | get (404 ถ้าไม่พบ) |
| POST | `/v1/assistants` | create (201) |
| PATCH | `/v1/assistants/{id}` | update (ชื่อ/prompt/model/params) |
| DELETE | `/v1/assistants/{id}` | delete (404 ถ้าไม่พบ) |

## 📦 Data model

```json
{
  "id": "cae607782386",

  "description": "test",
  "system_prompt": "Translate to Thai",
  "model_id": null,
  "params": {},
  "created_at": 1785854655801,
  "updated_at": 1785854655801

```

## 💾 Persistence

- เก็บ: `data/assistants/<id>.json` (1 ไฟล์/assistant)
- Honors `WS_DATA_DIR` (default `data`)
- local-first: ไม่ต้องใช้เน็ต (ตรงหลัก offline-first)

## ⚠️ บทเรียน (learned)

- **Pydantic body model ต้องอยู่ module-level** — ถ้านิยามใน function scope, FastAPI จะตีความเป็น query param (เกิด 422 `loc:["query","body"]`) → ย้ายไป schemas.py + import top-level
