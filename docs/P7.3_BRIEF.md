# 📋 P7.3 Brief — Tool-Calling Protocol

> **Status:** ✅ เสร็จ (backend) · **Date:** 2026-08-04
> **ที่มา:** Jan tool-calling (docs/P7_PLAN.md §C) + มติผู้ใช้
> **หลักการ:** ทำให้ระบบเป็น OpenAI-compatible endpoint ที่ IDE ต่อเข้ามาใช้ tool ได้

---

## 🎯 เป้าหมาย

ให้ IDE (Cursor/Continue/Claude Code/OpenCode) ต่อเข้ากับระบบเรา แล้วส่ง tools → ได้ tool_calls → ส่งผลกลับ → โมเดลตอบต่อ (protocol เต็มรูปแบบ)

## 📂 ไฟล์ที่แก้

| ไฟล์ | งาน |
|------|-----|
| `weight_stream/backends/llama_server.py` | stream_chat รับ `tools`/`tool_choice` → ส่ง server + accumulate tool_calls |
| `weight_stream/server/model_manager.py` | chat_completion คืน `tool_calls` |
| `weight_stream/server/openai_compat.py` | ส่ง tools + คืน tool_calls ใน response |
| `weight_stream/server/schemas.py` | ChatMessage รองรับ `tool` role + `tool_calls` field |

## 🔌 วิธีทำงาน

```
Client (IDE)                          Server (เรา)                    llama-server
─────────────────                    ──────────────                  ───────────
POST /v1/chat/completions
  { messages, tools: [...], ... }   →  รับ tools → ส่ง tools →  โมเดลตัดสินใจ
                                                                  ↓
  ← { tool_calls: [{name, args}] }  ←  คืน tool_calls  ←  delta tool_calls accumulated
                                                                  ↓
POST (role: tool, tool_call_id)
  { messages, tool result }          →  ส่งผล tool →  โมเดลตอบต่อ
```

## 📦 Tool call format (OpenAI-compatible)

```json
[{
  "id": "zBrkrT90...",
  "type": "function",
  "function": { "name": "get_weather", "arguments": "{\"city\":\"Bangkok\"}" }
}]
```

## 🧪 หลักฐาน (tested 2026-08-04)

```
tool_calls: [{'id': 'zBrkrT90pXrffRF9eXLXcpHybjIDlCe9', 'type': 'function',
              'function': {'name': 'get_weather', 'arguments': '{"city":"Bangkok"}'}}]
content: [thinking... (โมเดลเรียก tool ถูกต้อง)]
```

## 📌 งานที่เหลือ (frontend — ยังไม่ทำ)

- [ ] tool call cards ใน chat (แสดง args + approve/deny)
- [ ] execute tool ฝั่ง server (P7.4 — MCP host)

## ⚠️ บทเรียน (learned)

- **Indentation จาก edit tool** — เมื่อแก้ method ใหญ่ ต้องตรวจ indentation ของ method หลัง (stream_chat หลุด indent หลัง edit) → run `ast.parse` ก่อน commit
- **Streaming tool_calls** — ต้อง accumulate ตาม index (OpenAI ส่ง fragment) ไม่ใช่ overwrite
