## Do NOT translate (keep in Latin / as-is)
- Brand: `Weight Streaming`, `Console`
- Theme proper names: `Classic Dark`, `Aurora Dark`, `Aurora Light`
- Phase codes: `P2`, `P3`, `P5`
- Version token: `v{{version}}`
- Key combos: `Ctrl+K`, `Ctrl K`, `esc`, `↑↓`, `Enter`
- Endpoint / code / command text
- `n/a`, `OK`, `EN`, `TH`
- The status emoji in strings (e.g. the ✓ in "Copied ✓") — keep the glyph
