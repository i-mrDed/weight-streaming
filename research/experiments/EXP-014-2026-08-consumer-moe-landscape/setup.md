# EXP-014 — ใครรัน MoE 300B–2.8T บน consumer hardware ได้จริง (2026-08-10)?

## คำถาม

1. ณ ส.ค. 2026 มีใครรันโมเดลระดับ 300B–2.8T (ถึง Kimi K3) บน hardware
   consumer ที่ใกล้เคียงกับเครื่องเรา และ**ใช้ทำงานได้จริง** ไหม?
2. มีแนวทาง/engine ใหม่ที่นอกเหนือจาก llama.cpp หรือไม่ — และเรา
   ยืมไอเดียอะไรได้บ้าง ภายใต้ข้อจำกัด **คงที่** (ห้ามเพิ่ม hardware)?

## ข้อจำกัดของเครื่องเรา (hard constraint — เพิ่มไม่ได้)

| ส่วน | ค่า |
|---|---|
| CPU | i9-9900KF (8C/16T, DDR4 ~42–51 GB/s) |
| GPU | RTX 3060 12 GB VRAM |
| RAM | 64 GB |
| OS | Windows |
| Disk | NVMe (วัดได้ ~เร็วพอ stream แต่ไม่ใช่ Gen5 7 GB/s แน่นอน) |

## วิธี

- Web research (Reddit/HN/GitHub/Medium/arXiv) ณ 2026-08-10
- เทียบกับผลวัดจริงของเรา (EXP-012: DS V4 Flash 104 GB = 1.48–1.89 tok/s)
- คะแนนเปรียบเทียบแบบเดียวกับ EXP-013 (71/120 kimi-k3-in-c)

## เกณฑ์ "ใช้ทำงานได้จริง"

- โต้ตอบได้ลื่นพอสำหรับงานจริง: ≥ 5 tok/s = ใช้งานได้สบาย,
  1–5 tok/s = ใช้ได้แบบอดทน (chat ยาวไม่ได้), < 1 tok/s = รันได้แต่ยังใช้จริงไม่ได้
