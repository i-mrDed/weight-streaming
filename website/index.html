How It Works

🗂️

Memory-Mapped File

Zero-copy access to the GGUF model file via mmap. No redundant loading into RAM — the OS manages page faults.

🧠

Smart LRU Buffer

64 MB shard-based buffer tracks which weights are hot. LRU eviction ensures frequently-used layers stay resident.

🔮

Heuristic Predictor

Sequential + co-occurrence pattern detection predicts which experts will be needed next. No MLP required.

⚡

Background Prefetch

Expert-aware prefetch loads predicted shards during compute time. I/O overlaps with inference — zero overhead.

Quick Start

1. Install

pip install weight-streaming[llama-cpp]

2. Start API Server

python -m weight_stream server --model model.gguf

3. Generate Text (CLI)

python -m weight_stream run model.gguf \
  --prompt "Hello" --max-tokens 100

4. Or Use Python API

from weight_stream import WeightStreamModel
model = WeightStreamModel("model.gguf")
output = model.generate("Hello")
print(output)
