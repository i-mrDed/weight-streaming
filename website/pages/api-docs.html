API Documentation

Weight Streaming provides a REST API, WebSocket streaming, and an OpenAI-compatible endpoint.

REST API Python API OpenAI Compat Anthropic Compat WebSocket

REST API

Base URL: http://localhost:8765

POST /v1/generate

Generate text from a loaded model. Supports SSE streaming via stream: true.

Request

{
  "model": "default",
  "prompt": "The capital of France is",
  "max_tokens": 128,
  "temperature": 0.7,
  "top_p": 0.9,
  "stream": false
}

Response (non-streaming)

{
  "model": "default",
  "output": " Paris. It is known for its art...",
  "tokens_generated": 10,
  "elapsed_seconds": 3.24,
  "tokens_per_second": 3.09,
  "stats": {
    "buffer": { "hit_rate": 0.0, "hot_shards": 16, "capacity_shards": 16 },
    "prefetcher": { "prefetched": 42, "queued": 3 },
    "page_cache": { "resident_ratio": 0.016, "resident_gb": 0.09 }
  }
}

Using curl

curl -X POST http://localhost:8765/v1/generate \
  -H "Content-Type: application/json" \
  -d '{"model":"default","prompt":"Hello","max_tokens":20}'

GET /v1/stats

Get performance statistics for loaded models.

curl http://localhost:8765/v1/stats
curl http://localhost:8765/v1/stats?model=default

GET /v1/models

List all loaded models.

curl http://localhost:8765/v1/models

POST /v1/models/load

curl -X POST http://localhost:8765/v1/models/load \
  -H "Content-Type: application/json" \
  -d '{"model_id":"mixtral","model_path":"mixtral-8x7b.gguf","buffer_mb":128,"n_ctx":4096}'

POST /v1/models/unload

curl -X POST http://localhost:8765/v1/models/unload \
  -H "Content-Type: application/json" \
  -d '{"model_id":"mixtral"}'

Python API

Direct Model Access

from weight_stream import WeightStreamModel

model = WeightStreamModel(
    "model.gguf",
    buffer_mb=64,
    n_ctx=512,
)
output = model.generate("Hello world", max_tokens=100)
stats = model.get_stats()
model.close()

# Or use context manager
with WeightStreamModel("model.gguf", buffer_mb=64) as model:
    output = model.generate("Tell me a story", max_tokens=200)
    print(output)

API Client (connect to server)

import requests

# Generate
r = requests.post("http://localhost:8765/v1/generate", json={
    "model": "default",
    "prompt": "Explain AI",
    "max_tokens": 100,
    "stream": True,  # Enable SSE streaming
})
for line in r.iter_lines():
    if line.startswith(b"data: "):
        event = json.loads(line[6:])
        print(event["token"], end="", flush=True)

OpenAI-Compatible Endpoint

The POST /v1/chat/completions endpoint follows the OpenAI chat completion format. Any tool that speaks OpenAI API can connect directly.

Chat Completions

curl -X POST http://localhost:8765/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "default",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "What is the capital of France?"}
    ],
    "max_tokens": 100,
    "temperature": 0.7,
    "stream": false
  }'

OpenAI Python SDK

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8765/v1",
    api_key="not-needed",
)
response = client.chat.completions.create(
    model="default",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.choices[0].message.content)

LangChain

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="default",
    openai_api_base="http://localhost:8765/v1",
    openai_api_key="not-needed",
)
response = llm.invoke("Hello!")
print(response.content)

Anthropic-Compatible Endpoint

The POST /v1/messages endpoint follows the Anthropic Messages API format. Use this with Claude Code or any tool expecting the Anthropic API.

Chat

curl -X POST http://localhost:8765/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: not-needed" \
  -d '{
    "model": "default",
    "messages": [{"role": "user", "content": "Hello"}],
    "max_tokens": 100
  }'

Claude Code (CLI)

export ANTHROPIC_BASE_URL=http://localhost:8765/v1
export ANTHROPIC_API_KEY=not-needed
claude

Windows: $env:ANTHROPIC_BASE_URL="http://localhost:8765/v1"

Anthropic Python SDK

from anthropic import Anthropic

client = Anthropic(
    base_url="http://localhost:8765/v1",
    api_key="not-needed",
)
response = client.messages.create(
    model="default",
    messages=[{"role": "user", "content": "Hello"}],
    max_tokens=100,
)
print(response.content[0].text)

WebSocket Streaming

Endpoint: ws://localhost:8765/v1/stream

Client → Server

{"type": "generate", "model": "default", "prompt": "Hello", "max_tokens": 100}

Server → Client (streaming)

{"type": "token", "text": " Hello", "index": 0}
{"type": "token", "text": " world", "index": 1}
{"type": "done", "stats": {...}}

JavaScript Example

const ws = new WebSocket("ws://localhost:8765/v1/stream");
ws.onmessage = (e) => {
  const msg = JSON.parse(e.data);
  if (msg.type === "token") process.stdout.write(msg.text);
  if (msg.type === "done") console.log("Complete");
};
ws.send(JSON.stringify({
  type: "generate", model: "default",
  prompt: "Hello", max_tokens: 100,
}));
