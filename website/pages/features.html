Features

🗂️

Memory-Mapped Access

The GGUF model file is memory-mapped (mmap) for zero-copy access. The operating system manages virtual memory — pages are loaded on demand via hardware page faults. No redundant RAM consumption.

File size: any · RAM used: ~64 MB · Access: read-only

🧠

LRU Streaming Buffer

A 64 MB shard-based buffer tracks which weight shards are hot. LRU eviction ensures frequently-used layers stay resident while cold shards are ejected. Each shard is 4 MB.

Capacity: 64 MB (16 shards) · Hit rate: 93.8% at 64 MB · Policy: LRU only

🔮

Heuristic Predictor

Predicts which weight shards will be needed next using:

  • Sequential pattern detection (layer scanning)
  • Co-occurrence tracking (frequently paired experts)
  • No MLP required — instant, zero training
⚡

Background Prefetcher

A dedicated background thread reads predicted shards from NVMe while the inference engine computes the current token. I/O is fully overlapped with computation.

Thread: 1 · Queue: bounded · Priority: FIFO

Expert-Aware Prefetch

GGUF Metadata Parser

Parses the GGUF format to map every tensor to its file offset. For Qwen1.5-MoE: 411 tensors → 72 expert tensors (24 layers × 3 projections). Per-expert size: ~2.9 MB total, ~990 KB per projection.

get_expert_map() → {layer: {expert_idx: [gate, up, down]}}

Round-Robin Layer Prefetch

During generation, every 3rd token triggers expert prefetch for the next layer. While expert routing is opaque from Python, round-robin ensures all layers stay warm.

Strategy: round-robin · Interval: every 3 tokens · Per-token: 1 layer of experts

Observability

📊

Windows Page Cache Monitor

Uses QueryWorkingSetEx Windows API to sample physical RAM residency of the mmap'd file. Reports:

  • Resident ratio: % of file pages in RAM
  • Resident GB: actual pages loaded
  • Total GB: full file size

Example: 1.6% of 5.5 GB = 88 MB resident after cold generation

📈

Performance Statistics

Real-time stats available via model.get_stats():

  • Buffer: hit rate, hot shards, evictions, prefetches
  • Prefetcher: queued, prefetched, useful prefetches
  • Generation: tokens, elapsed, tokens/sec
  • Page cache: resident ratio, GB in RAM
