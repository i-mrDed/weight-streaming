Architecture

Weight Streaming is a three-layer system: Frontends → API Server → Backend Engine. All layers are modular and independently replaceable.

Component Breakdown

StreamingBuffer

LRU cache over a shared mmap. Tracks 4 MB shards. Zero-copy access via memoryview. Provides hit/miss/prefetch/eviction statistics.

python
buf = StreamingBuffer(mmap_obj, total_size_mb)
buf.access(offset, size)
buf.prefetch([shard_ids])
buf.get_stats()

Prefetcher

Background thread with bounded queue. Reads predicted shards from mmap to trigger OS page-in. Expert-aware: prefetches specific expert weight ranges.

python
prefetcher.start()
prefetcher.prefetch_experts(ranges)
prefetcher.stop()

HeuristicPredictor

Tracks sequential access patterns and shard co-occurrence. No MLP training needed. Predicts next likely shards based on recent history.

python
predictor.record(shard_id)
next_shards = predictor.predict(k=5)

GGUF Parser

Wraps the official gguf library. Maps all tensors to file offsets. Expert-aware: groups gate/up/down projections per expert per layer.

python
parser = GGUFParser("model.gguf")
expert_map = parser.get_expert_map()
# {layer: {expert_idx: [ExpertRange]}}

WindowsPageMonitor

Uses QueryWorkingSetEx Windows API to sample physical memory residency. Pure Python + ctypes. No admin required.

python
monitor = WindowsPageMonitor(mmap_addr, size)
monitor.sample_resident_pages()
ratio = monitor.get_resident_ratio()

ModelManager

Async model lifecycle manager. Handles load/unload/reload with asyncio locks. Auto-idle unload after configurable timeout. Thread-safe generation.

python
await manager.load("mixtral", "model.gguf")
await manager.generate_stream("mixtral", prompt)
await manager.unload("mixtral")

Request Flow

User → Frontend → API Server → ModelManager → WeightStreamModel
                                                        ├─ Buffer (LRU)
                                                        ├─ Prefetcher (predict + load)
                                                        ├─ Predictor (heuristic)
                                                        └─ llama.cpp (inference)
                                                                       └─ GGUF File (mmap'd)
