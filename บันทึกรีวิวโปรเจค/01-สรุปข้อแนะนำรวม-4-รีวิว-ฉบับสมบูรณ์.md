## หมวด A — 🔴 เร่งด่วนสุด: Security & robustness fixes (OpenCode W1–W5 — ตรวจยืนยันแล้วทุกจุด)

**เหตุผลที่ต้องมาก่อนทุกอย่าง:** repo เปิด public แล้ว + W2 (CORS) ทำให้เว็บเพจใดก็ได้ที่เปิดใน browser ส่ง request มาที่ localhost ได้ → W3 (RCE ผ่าน MCP) และ W5 (path traversal ลบ/อ่านไฟล์นอก dir) กลายเป็น **drive-by exploit ได้จากแค่เปิดเว็บ** แม้ default bind จะเป็น 127.0.0.1

| # | ปัญหา (verified) | ตำแหน่ง | ผลกระทบ |
|---|---|---|---|
| W1 | **Deadlock ใน `load()` eviction** — ครอบ `_dict_lock` แล้วเรียก `unload()` ที่ครอบซ้ำ (asyncio.Lock ไม่ reentrant) | `model_manager.py:143-178, 228` | โหลดเกิน max models → server ค้างถาวรต้อง restart |
| W2 | **CORS `["*"]` + `allow_credentials=True`** — Starlette echo origin → browser ยอม credentialed request จากเว็บใดก็ได้ | `api_server.py:226-233` | drive-by: ลบไฟล์/load/unload/ตั้ง config/สั่ง MCP |
| W3 | **MCP รับ `command`/`args` อิสระจาก API → RCE** ไม่มี allowlist | `mcp_host.py:103-123`, `api_server.py:1233-1246` | `POST /v1/mcp/servers` spawn process จริง → RCE |
| W4 | **GGUF parse fail → mmap ไฟล์ >100GB + fd รั่ว** (Step 3 except ไม่ปิด) | `backends/llama_cpp.py:148-153` | resource exhaustion ทุกครั้งที่โหลดไฟล์เสีย |
| W5 | **Path traversal Windows (confirmed)** — `assistant_id`/`issue_id` ต่อตรง `os.path.join` ไม่ validate; Starlette block `%2F` แต่ไม่ block `%5C` | `assistant.py:54-55`, `issues/store.py:49-53` | อ่าน/เขียน/ลบ .json นอก dir |

**วิธีแก้ที่ OpenCode แนะนำ:** (1) CORS allowlist `localhost:*` + ปิด credentials + ตรวจ Host header กัน DNS rebinding · (2) MCP command ต้องมาจากไฟล์ config ที่ user ตั้งเอง ไม่ใช่ API · (3) regex `^[A-Za-z0-9_-]+$` สำหรับ id · (4) fix deadlock + fix leak · (5) upper bounds `n_ctx`/`buffer_mb` + cap hub concurrency + default `WS_HUB_MAX_BYTES`

## หมวด F — รายการตรวจสอบอื่นของ OpenCode (Low/Medium — บันทึกเป็น known issues)

- `StreamingBuffer` ไม่มี lock แต่ใช้จาก 2 thread (W6) · sync งานหนักบน generation thread → latency กระตุก (W7) · `_OWNED_PIDS` TOCTOU (W8) · MCP SSE url + hub redirect → SSRF (W9) · `/v1/models/scan?dir=` path อิสระ + ไม่มี upper bound (W10) · global lock ครอบตลอด load หลายนาที (W11) · `WS_HUB_MAX_BYTES` default 0 = unlimited (W12)
- Frontend: side effects ใน render, re-parse markdown ทุก frame, race `loadLatest`, theme auto-mode ไม่ re-apply
- `prefetcher._queue` ไม่มีอยู่จริง → `queued: 0` ตลอด (telemetry ปลอมเงียบ) — ตรงข้ามกับกฎ honest telemetry ต้องแก้
- ไม่ได้รัน test/browser จริง (static review) + Python CI ครอบแค่ Windows — ควรเพิ่ม Linux CI
